# wujunjie1998.github.io
Repository for Junjie Wu's academic research website.

## Local preview

Run `python3 scripts/preview.py` and open <http://127.0.0.1:8000>.
The page refreshes automatically when website files change and preserves your
scroll position. The preview server does not modify the served HTML files.
Use `--port 8001` to choose another port, or press Ctrl+C to stop the server.
